# 테스트 코드 작성 컨벤션

## 적용 범위

테스트를 작성하거나 수정하기 전에 이 문서를 반드시 읽고 따른다.
공통 테스트와 플랫폼별 테스트에 동일하게 적용한다.

## 테스트 함수명

- 테스트 함수명은 백틱으로 감싼 한글 문장으로 작성한다.
- 이름만으로 테스트가 검증하는 조건과 기대 동작을 알 수 있도록 작성한다.

```kotlin
@Test
fun `온보딩 완료를 재시도해도 알람을 추가로 생성하지 않는다`() {
    // 테스트 준비, 실행 및 검증
}
```

영어 함수명 대신 다음과 같이 작성한다.

```kotlin
// 변경 전
@Test
fun completionRetryDoesNotCreateAnotherAlarm() {
    // 테스트 준비, 실행 및 검증
}

// 변경 후
@Test
fun `온보딩 완료를 재시도해도 알람을 추가로 생성하지 않는다`() {
    // 테스트 준비, 실행 및 검증
}
```
