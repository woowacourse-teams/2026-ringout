# 모임 기능 비활성화

모임 재도입 여부가 정해지지 않아 화면, API, 푸시 및 분석 구현과 테스트를 보존한다. 공통 `domain/room/RoomFeature.kt`의 `RoomFeature.isEnabled`는 현재 `false`이며, Android와 iOS가 같은 빌드 설정을 따른다. 원격 설정이나 사용자 설정으로 변경하지 않는다.

## 비활성 상태

- 소셜 탭을 표시하지 않고 모임 화면 직접 진입 및 푸시 이동을 차단한다.
- 모임 API 요청과 모임 활동의 신규 대기열 생성·전송·재시도를 중단한다. 개인 알람과 미션 기록은 기존처럼 저장하고 동기화한다.
- 모임 이벤트와 사용자 속성, 개인 미션 이벤트의 모임 참여 속성 수집·전송을 중단한다. 기존 분석 저장값은 삭제하지 않는다.
- 기존 모임 알림을 누르면 일반 앱 진입으로 처리한다. 알람·진행 중 미션·미확인 도착 결과의 우선순위는 유지한다.
- 서버 모임 데이터와 업데이트 전 로컬 모임 전송 대기열을 삭제하지 않는다. DB 버전·테이블은 유지한다. 기존 로그아웃·회원 탈퇴 시 로컬 계정 데이터 정리 정책은 그대로 적용된다.
- iOS 네이티브 저널 정리는 개인 기록 저장·전송 증명을 유지하며 비활성화된 모임 대기열 때문에 정체되지 않는다.

## 푸시 운영

앱이 직접 처리하는 포그라운드 모임 알림은 표시하지 않는다. 백그라운드에서는 운영체제가 FCM/APNs 알림 페이로드를 직접 표시할 수 있으므로, 신규 모임 알림을 완전히 중단하려면 서버 발송도 중단해야 한다. 일반 푸시 토큰 등록과 알람 알림은 유지한다.

## 재도입 검증

설정 변경만으로 배포하지 않는다. 서버 API·인증·푸시 계약, 기존 대기열의 재전송 여부, 분석 속성의 최신성 및 양 플랫폼 화면·알람 회귀를 먼저 검토한다. 비활성화 기간의 과거 모임 대기열을 재개할지 폐기할지는 재도입 시 별도로 결정한다. 테스트에서는 활성 설정을 명시해 보존된 동작도 검증한다.
